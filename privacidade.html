Política de Privacidade

Esta política explica como o Grano trata as informações utilizadas durante a experiência no aplicativo.

1. Sobre o Grano

O Grano é um aplicativo desenvolvido para ajudar você a organizar seus grãos, explorar diferentes métodos de preparo e acompanhar suas experiências com café especial.

O aplicativo foi desenvolvido para funcionar com os dados armazenados localmente no dispositivo do usuário.

2. Dados utilizados pelo aplicativo

O Grano permite que o usuário registre informações relacionadas à sua experiência com café, como:

grãos cadastrados e suas características, quantidade de grãos disponível, cafés preparados, métodos de preparo, proporções de café e água, etapas e configurações de preparo e outras informações inseridas pelo próprio usuário para utilizar as funcionalidades do aplicativo.

Essas informações são armazenadas localmente no dispositivo, por meio do SwiftData, e são utilizadas para disponibilizar as funcionalidades do Grano.

3. Coleta e transmissão de dados

O Grano não coleta dados pessoais ou dados de uso dos usuários.

As informações inseridas no aplicativo não são enviadas para servidores do Grano ou para serviços externos. O aplicativo não possui sistema de contas ou login e não exige o envio de informações pessoais para funcionar.

4. Compartilhamento com terceiros

O Grano não vende, aluga ou compartilha informações dos usuários com terceiros.

O aplicativo também não utiliza serviços de publicidade, ferramentas de analytics ou mecanismos de rastreamento para coletar informações sobre seus usuários.

5. Rastreamento

O Grano não rastreia a atividade dos usuários em outros aplicativos, sites ou serviços.

O aplicativo não utiliza os dados armazenados localmente para publicidade direcionada, medição de publicidade ou criação de perfis de usuários.

6. Armazenamento e exclusão

Os dados utilizados pelo Grano permanecem armazenados localmente no dispositivo do usuário enquanto forem mantidos pelo aplicativo.

Como o Grano não mantém uma cópia desses dados em servidores próprios ou de terceiros, não existe uma base de dados externa do Grano da qual seja necessário solicitar a exclusão.

O usuário pode excluir os dados armazenados localmente por meio das funcionalidades disponíveis no aplicativo ou, quando aplicável, pela remoção do aplicativo do dispositivo.

7. Segurança

Como os dados registrados no Grano são armazenados localmente e não são enviados aos servidores do Grano, o aplicativo não mantém uma base de dados centralizada com as informações dos usuários.

O usuário é responsável por manter a segurança e o acesso ao próprio dispositivo.

8. Alterações nesta Política de Privacidade

Esta Política de Privacidade poderá ser atualizada caso ocorram mudanças nas funcionalidades do Grano ou na forma como o aplicativo trata as informações dos usuários.

Caso o Grano passe a coletar, transmitir ou compartilhar algum tipo de dado, esta política será atualizada para refletir essas mudanças antes de sua implementação, quando aplicável.
